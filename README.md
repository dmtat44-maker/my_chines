# Китайский квест — MVP v19 Visible Interactive Football

## Что изменено

### 1. Начали новый правильный путь: сюжетный урок
Первый эталонный урок теперь строится не как набор карточек, а как мини-сцена:

- герой-футболист выходит на поле;
- тренер ждёт приветствие `你好`;
- ребёнок проходит языковой пароль;
- после правильных ответов открывается действие: команда отдаёт пас и тренировка начинается.

### 2. Первый герой: футболист
Стартовая роль — футболист. Урок 1 адаптирован под футбольную академию, команду, тренера и мяч.

### 3. Первый урок: приветствие
Слова урока:

- `你好` — nǐ hǎo — привет;
- `我` — wǒ — я;
- `是` — shì — быть / являться;
- `朋友` — péngyou — друг;
- `再见` — zàijiàn — до свидания / пока.

### 4. Убрали неправильный блок как тестовый вопрос
Фраза “Перед продолжением сюжета что нужно сделать?” больше не является перемешиваемым тестовым заданием.
Теперь это фиксированный блок управления с постоянным порядком:

1. Пройти пароль / перейти дальше;
2. Повторить фразу;
3. Подсказка;
4. Пропустить урок;
5. Закрыть.

### 5. Добавлена структура Story Lesson Engine
В код добавлены функции:

- `storyForDay()` — создаёт сюжетную сцену;
- `storyStageHtml()` — показывает сцены урока;
- `showHint()` — показывает подсказку;
- `skipDay()` — пропуск урока с подтверждением;
- `closeApp()` — выход на стартовый экран.

## Как открыть

Открой `index.html` в браузере.

Если раньше уже запускалась старая версия, это не помешает: у v19 новый `storageKey`.


## v19 — видимый интерактив

Добавлена первая визуальная интерактивная сцена для дня 1 и роли “Футболист”:

- футбольное поле;
- тренер;
- герой-футболист;
- мяч;
- ворота;
- прогресс сцены 0/3 → 3/3;
- сцена меняется после правильных ответов в “Языковом пароле”.

Это пока не полноценный мультик и не 3D-модель. Это прототип места, где позже будут Rive/Lottie/Spine-анимации или настоящие ассеты персонажа.


Обновление v19: вместо мяча используется голова мальчика/девочки, а интерактивная сцена добавлена в каждый день 1–10.


Обновление v19: блок “Главная фраза дня…” убран из детского урока и перенесён в кабинет родителя. Родитель теперь видит текущий день, тему, цель, главную фразу и слова дня.


Обновление v19: из детской сцены убран блок “Если ошибка”, из карточек и вопросов убрана формулировка “главное действие выбранной роли”.


Обновление v19: памятка тонов перенесена из основной детской части в блок “Перед продолжением сюжета”.


Обновление v19: при выборе роли “Маг” интерактивная сцена больше не футбольное поле. Появляется дорога к замку, хранитель и замок, до которого герой доходит по шагам после правильных ответов.
