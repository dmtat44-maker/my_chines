# Китайский квест — MVP v7

## Что изменено после теста

- Ответы в языковом пароле больше не стоят всегда на первом/втором месте.
- Варианты ответа перемешиваются стабильно для каждого дня.
- Каждый день получил `фразу дня`.
- Фразу дня можно прослушать целиком.
- Проверка теперь связана с миссией дня и словами урока.
- День 5 специально переделан под пример: “После тренировки я пью воду” / 训练以后，我喝水。

## Как обновить GitHub Pages

Загрузи новый `index.html` в корень репозитория `my_chines` вместо старого файла.

Ссылка после публикации:

```text
https://dmtat44-maker.github.io/my_chines/
```

## Как подключить ИИ

Ключ OpenAI нельзя класть в `index.html`. Для этого есть папка `backend`.

Локальный запуск:

```powershell
cd backend
pip install -r requirements.txt
$env:OPENAI_API_KEY="sk-..."
uvicorn main:app --reload --port 8000
```

В приложении в поле `AI backend URL` укажи:

```text
http://127.0.0.1:8000
```


## Изменения v6

- Убрана двусмысленная формулировка “выбери слово, которое нужно для миссии”.
- Теперь вопросы конкретные:
  - “как сказать синий цвет?”
  - “как сказать тренировка?”
  - “какие два слова нужны для фразы пью воду?”
  - “как сказать карта?”
- Проверка остаётся связанной с темой дня, но ребёнку понятно, что именно выбрать.


## Изменения v7

- Убраны технические кнопки из детского урока:
  - “Сгенерировать этот день через ИИ”
  - “Показать будущий голос/2D/3D”
- В уроке оставлено только то, что нужно ребёнку:
  - фраза дня;
  - прослушивание фразы;
  - слова;
  - памятка тонов;
  - языковой пароль.
- ИИ-генерация и будущая дорожная карта перенесены в кабинет родителя/разработчика.
