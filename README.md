# Китайский квест — MVP v11

## Что исправлено

### 1. Ролевые карточки теперь имеют нормальные тоны

В v10 в некоторых ролевых словах было написано:
- “тематическое слово”;
- “тематическое действие”;
- “слово локации”;
- “тематический предмет”.

В v11 это заменено на реальные тоны и подсказки.

Примеры:
- 练习 / liànxí — 4-й + 2-й;
- 跳舞 / tiàowǔ — 4-й + 3-й;
- 舞台 / wǔtái — 3-й + 2-й;
- 地图 / dìtú — 4-й + 2-й;
- 探险 / tànxiǎn — 4-й + 3-й.

### 2. Последний вопрос про правило входа больше не перемешивается

Вопрос:

“Перед продолжением сюжета что нужно сделать?”

теперь всегда имеет одинаковый порядок ответов:
1. пройти языковой пароль;
2. пропустить урок;
3. закрыть приложение;
4. не слушать фразу.

Это не учебная проверка, а правило механики приложения, поэтому порядок должен быть стабильным.

### 3. Учебные вопросы остаются перемешанными

Смысловые вопросы по словам, фразе дня и роли ребёнка продолжают перемешиваться, чтобы ребёнок не запоминал позицию ответа.
